Drop compressed web MP4s here.

Naming must match the `src` values in src/data/site.js, e.g.:
  showreel.mp4
  nova-campaign.mp4
  ramblers-brand.mp4
  motion-reel.mp4
  doc-short.mp4

Keep each file under ~40MB. GitHub hard-rejects anything over 100MB.
H.264, 1080p, ~8-10 Mbps is a good target for a showreel.
